# Submitting a documentation correction

Read CONTRIBUTING.md for current limits. Download the current main commit, edit an allowed documentation file locally, and submit its complete replacement contents with the full base SHA, a concise summary, actual test results, and explicit publication consent. Review the returned draft PR and feedback on the task. Cancel before revising an open submission.

This file is part of an operator-run end-to-end bridge verification. The test PR will be closed without merging.
